Introduction to Ruby

Welcome to my comprehensive documentation of learning Ruby on Rails! This site tracks my journey from the fundamentals of the Ruby language all the way through building full-featured web applications with Ruby on Rails.

Your First Steps Right Now​

1. Install Ruby​

Go to ruby-lang.org and install it, or use a version manager like rbenv or rvm.

2. Open IRB​

Open your terminal and type irb (Interactive Ruby). It's a live Ruby environment where you can type code and see results instantly.

irb
> 5 + 5
=> 10
> "Hello " + "World"
=> "Hello World"

3. Try These Commands​

5 + 5
"Hello " + "World"
name = "Ruby Learner"
puts "My name is #{name}"
[1, 2, 3].map { |x| x * 10 }
exit

What You'll Find Here​

  • Ruby Basics — Philosophy, variables, data types, control flow, methods, collections, blocks
  • Object-Oriented Programming — Classes, modules, inheritance, mixins
  • Advanced Ruby — Blocks, procs, lambdas, metaprogramming, error handling
  • Ruby on Rails — MVC architecture, Active Record, routing
  • Testing — RSpec, Minitest, TDD best practices
  • Best Practices — Code style, gems, Bundler, conventions

Prerequisites​

  • Basic programming knowledge (any language)
  • Familiarity with command line interfaces
  • A code editor (VS Code recommended with the Ruby extension)

Best Free Resources​
