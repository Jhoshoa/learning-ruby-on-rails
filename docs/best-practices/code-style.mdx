# Code Style

Ruby style is guided by community conventions, summarized in the Ruby Style
Guide.

## Key Conventions

- **Indentation**: 2 spaces (no tabs)
- **Variables & Methods**: `snake_case` (`my_variable`, `calculate_total`)
- **Classes & Modules**: `PascalCase` (`UserAccount`, `PaymentProcessor`)
- **Constants**: `UPPER_SNAKE_CASE` (`MAX_USERS`, `DEFAULT_TIMEOUT`)
- **File names**: `snake_case.rb`, matching the class name (`user_account.rb` contains `UserAccount`)
- **Line length**: maximum 80-120 characters

## Idiomatic Ruby

```ruby
# Bad
if user != nil
  puts user.name
end

# Good
puts user.name if user
```

```ruby
# Bad
x = 5
if x > 0
  return true
else
  return false
end

# Good
x > 0
```

## Linting

Use `rubocop` to enforce consistent style:

```bash
gem install rubocop
rubocop
```
