# Introduction to Ruby

Welcome to my comprehensive documentation of learning **Ruby on Rails**! This site
tracks my journey from the fundamentals of the Ruby language all the way through
building full-featured web applications with Ruby on Rails.

## Why Ruby?

Ruby is a dynamic, open-source programming language known for its simplicity and
productivity. It was designed by **Yukihiro "Matz" Matsumoto** in 1995 with a
focus on developer happiness and human-readable syntax.

```ruby
puts "Hello, Ruby!"
```

## What You'll Find Here

- **Ruby Basics** - Variables, data types, control flow, methods, collections
- **Object-Oriented Programming** - Classes, modules, inheritance, mixins
- **Advanced Ruby** - Blocks, procs, lambdas, metaprogramming, error handling
- **Ruby on Rails** - MVC architecture, Active Record, routing
- **Testing** - RSpec, Minitest, TDD best practices
- **Best Practices** - Code style, gems, Bundler, conventions

## Prerequisites

- Basic programming knowledge (any language)
- Familiarity with command line interfaces
- A code editor (VS Code recommended with the Ruby extension)

Let's begin the journey!
