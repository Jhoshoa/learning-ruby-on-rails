# Introduction to Ruby

Welcome to my comprehensive documentation of learning **Ruby on Rails**! This
site tracks my journey from the fundamentals of the Ruby language all the way
through building full-featured web applications with Ruby on Rails.

## Your First Steps Right Now

### 1. Install Ruby

Go to [ruby-lang.org](https://www.ruby-lang.org/) and install it, or use a
version manager like `rbenv` or `rvm`.

### 2. Open IRB

Open your terminal and type `irb` (Interactive Ruby). It's a live Ruby
environment where you can type code and see results instantly.

```bash
irb
> 5 + 5
=> 10
> "Hello " + "World"
=> "Hello World"
```

### 3. Try These Commands

```ruby
5 + 5
"Hello " + "World"
name = "Ruby Learner"
puts "My name is #{name}"
[1, 2, 3].map { |x| x * 10 }
exit
```
