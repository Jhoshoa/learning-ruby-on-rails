# Data Types

Everything in Ruby is an **object** — including numbers, strings, and even
`true`, `false`, and `nil`. There are no "primitive" types.

```ruby
5.class         # => Integer
3.14.class      # => Float
"hello".class   # => String
true.class      # => TrueClass
false.class     # => FalseClass
nil.class       # => NilClass
```

Because everything is an object, every value has methods:

```ruby
5.times { print "Hi " }    # => Hi Hi Hi Hi Hi
-10.abs                     # => 10
"hello".upcase              # => "HELLO"
```

## Numbers

```ruby
# Integer
42
-10

# Float
3.14
-0.5

# Arithmetic
sum = 5 + 3
difference = 10 - 4
product = 6 * 7
quotient = 20 / 5
power = 2 ** 10
modulus = 17 % 5
```

## Strings

Text wrapped in single `' '` or double `" "` quotes. Double quotes allow
**interpolation** — inserting variables into strings.

```ruby
single_quoted = 'Hello'
double_quoted = "World"

# Interpolation (double quotes only)
name = "Ruby"
greeting = "Hello, #{name}!"      # => "Hello, Ruby!"

# Common methods
"hello".upcase                    # => "HELLO"
"HELLO".downcase                  # => "hello"
"hello".capitalize                # => "Hello"
"hello".length                    # => 5
"hello".reverse                   # => "olleh"
```

## Symbols

Symbols are **unique to Ruby**. A symbol looks like `:name`. Think of it as a
lightweight, immutable string. You will see them everywhere in Ruby, especially
as keys in hashes.

```ruby
:name
:status
:active

# Symbols as hash keys (this is the modern Ruby style)
user = {name: "Alice", age: 30, role: :admin}
user[:name]  # => "Alice"
```

Unlike strings, two identical symbols are the same object in memory:

```ruby
"name".object_id == "name".object_id  # => false (different objects)
:name.object_id == :name.object_id    # => true (same object)
```

## Booleans and Nil

```ruby
true
false
nil  # Ruby's version of "nothing" or "no value"
```

## Type Checking

```ruby
"hello".is_a?(String)  # => true

```
