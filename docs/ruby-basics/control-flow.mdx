# Control Flow

Ruby has standard `if/else` statements, but adds elegant twists like `unless`
and implicit returns.

## If / Elsif / Else

```ruby
age = 18

if age >= 18
  puts "You can vote"
elsif age >= 16
  puts "You can drive"
else
  puts "You are young"
end
```

## Unless

The exact opposite of `if`. It runs the code only if the condition is **false**.

```ruby
unless user.logged_in?
  redirect_to_login
end

# One-liner modifier
puts "Minor" unless age >= 18
```

## One-liner Modifiers

Ruby lets you append conditionals at the end of a single line for clean,
readable code:

```ruby
puts "Adult" if age >= 18
puts "Minor" unless age >= 18
```

## Implicit Returns

In Ruby, you don't need to write `return` at the end of a method. Ruby
automatically returns the result of the **last evaluated expression**.

```ruby
def add(a, b)
  a + b  # This is automatically returned
end

def is_adult?(age)
  age >= 18  # Returns true or false
end

add(2, 3)      # => 5
is_adult?(20)  # => true
```

## Case Expressions

```ruby
status = :active

case status
when :active
  puts "User is active"
when :inactive
  puts "User is inactive"
when :banned
  puts "User is banned"
else
  puts "Unknown status"
end
```

## Loops

Ruby rarely uses traditional `for` loops. Instead, use iterators (see
[Blocks & Iterators](/docs/ruby-basics/blocks-iterators)).

```ruby
# While loop
count = 0
while count < 5
  puts count
  count += 1
end

# Until loop
count = 0
until count == 5
  puts count
  count += 1
end
```
