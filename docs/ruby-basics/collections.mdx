# Collections

Ruby provides two essential collection types for grouping data: Arrays and
Hashes.

## Arrays

Ordered lists of items, indexed by integer.

```ruby
colors = ["red", "green", "blue"]
numbers = [1, 2, 3, 4, 5]
mixed = [1, "two", :three, 4.0]

# Accessing elements
colors[0]     # => "red"
colors.first  # => "red"
colors.last   # => "blue"

# Adding elements
colors << "yellow"       # append (shovel operator)
colors.push("purple")    # append
colors.unshift("orange") # prepend

# Removing elements
colors.pop          # remove last
colors.shift        # remove first
colors.delete("red")

# Iteration
colors.each { |color| puts color }

# Transformation
numbers.map { |n| n * 2 }      # => [2, 4, 6, 8, 10]
numbers.select { |n| n.even? } # => [2, 4]
```

## Hashes

Key-value pairs (like Dictionaries in Python or Objects in JavaScript). In
modern Ruby, you almost always use Symbols as the keys.

```ruby
# Old syntax (hash rockets)
user = {"name" => "Alice", "age" => 25}

# Modern syntax (symbol keys — preferred)
user = {name: "Alice", age: 25, role: :admin}

# Accessing values
user[:name]  # => "Alice"

# Adding/updating
user[:email] = "alice@example.com"

# Iteration
user.each do |key, value|
  puts "#{key}: #{value}"
end

# Default values
counts = Hash.new(0)
counts[:apple] += 1   # no error, defaults to 0
counts[:apple]        # => 1
```
