frum is a Ruby version manager written in Rust. It is the best option for Windows — fast, works in PowerShell, uses `.ruby-version` files like rbenv.

Reference: [frum on GitHub](https://github.com/TaKO8Ki/frum)

## Install

Open PowerShell **as Administrator** and run:

```powershell
# Using winget (Windows Package Manager)
winget install frum
```

Or use Scoop:

```powershell
scoop bucket add main
scoop install frum
```

## Shell Setup

Add to your PowerShell profile (`notepad $PROFILE`):

```powershell
frum init | Add-Content
```

Then restart PowerShell or reload:

```powershell
. $PROFILE
```

## Usage

```powershell
# List installable versions
frum install -l

# Install a version (downloads precompiled binary — fast)
frum install 3.4.1

# Set global default
frum global 3.4.1

# Set per-project version (creates .ruby-version file)
cd my-project
frum local 3.4.1

# Verify
ruby --version
```

## Notes

- frum downloads precompiled Ruby binaries — no compilation needed. Install takes seconds, not minutes.
- `.ruby-version` files are compatible with rbenv. Same file works cross-platform on a team.
- If `winget` / `scoop` are not available, download the [latest release from GitHub](https://github.com/TaKO8Ki/frum/releases) and add the binary to your PATH manually.
